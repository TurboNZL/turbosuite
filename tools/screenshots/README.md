# How the screenshots were made

Every image on the site is a real capture of the running app (Chromium through Playwright, 1440x900 for desktop, 390x844 for phone), filled with sample data that these scripts create. Nothing is generated by an image model, drawn, or edited, apart from cropping the empty lower part of a few pages (see `make-images.py`).

The sample data is invented (fictional artists and albums, a made-up household, a pretend budget). The video in the TurboCut capture is a synthetic gradient made with `ffmpeg`, and the audio behind TurboMusic's tracks is a synthesised tone, so TurboMusic shows its own placeholder cover art because no real covers were used.

## What you need
- Node 22, pnpm 10, `ffmpeg`, Python 3 with Pillow, and Playwright (`PLAYWRIGHT_MODULE=<path to playwright's index.mjs>` if it is not resolvable; `CHROMIUM=<binary>` to choose a browser).
- A checkout of each app next to each other, `pnpm install --ignore-scripts --frozen-lockfile` in each.

## Run the apps (each on its own port, so they can all run at once)
| App | Start | Seed | Capture |
|---|---|---|---|
| TurboBudget | `npx vite --port 5301` | in `budget.mjs` (written to `localStorage`) | `node budget.mjs` |
| TurboCut | `npx vite --port 5302` | `ffmpeg` clips, see below | `node cut.mjs` |
| TurboDocs | `npx vite --port 5303` in `apps/web` | typed into the editors by `docs.mjs` / `slides.mjs` | `node docs.mjs`, `node slides.mjs` |
| TurboKeep | server: `TURBOKEEP_DATA=<dir> TURBOKEEP_ADMIN_USER=demo TURBOKEEP_ADMIN_PASSWORD=demo-password-1 npx tsx src/server.ts` in `apps/server` (port 47901), web: `npx vite --port 5304` in `apps/web` | `node seed-keep.mjs` | `node keep.mjs`, `node keep-note.mjs` |
| TurboPantry | server: `TURBOPANTRY_DATA=<dir> TURBOPANTRY_UPDATE=0 node --experimental-strip-types src/index.ts` in `packages/server` (47900), `... index.ts add-user Luka` prints a token, web: `npx vite --port 5305` in `apps/web` | `node seed-pantry.mjs <token>` | `node pantry.mjs <token>` |
| TurboMusic | server: `TURBOMUSIC_DATA_DIR=<dir> node --experimental-strip-types src/index.ts` in `packages/server` (47813, prints a token), web: `npx vite --port 5306` in `apps/web` | `node seed-music.mjs <token>` (needs `audio/t1.mp3` .. `t4.mp3`) | `node music.mjs <token>`, `node looks.mjs <token>` |

The captures are written to `./raw` (create it); `OUT=<dir>` changes that. Then `python3 -I make-images.py raw ../../site/img/screens` makes the WebP files the site serves.

## The synthetic media
```
# TurboCut: two 1080x1920 gradient clips with a tone (media/morning-clip.webm, media/closing-clip.webm)
ffmpeg -f lavfi -i "gradients=size=1080x1920:rate=30:duration=8:speed=0.04:c0=0xe10600:c1=0x14c8d8:c2=0x1b1b24:c3=0xffb347:nb_colors=4" -f lavfi -i "sine=frequency=330:sample_rate=48000:duration=8" -c:v libvpx-vp9 -b:v 2M -deadline realtime -cpu-used 8 -c:a libopus media/morning-clip.webm
ffmpeg -f lavfi -i "gradients=size=1080x1920:rate=30:duration=6:speed=0.06:c0=0x2f8bff:c1=0x8e44ad:c2=0x0b0b0e:nb_colors=3" -f lavfi -i "sine=frequency=262:sample_rate=48000:duration=6" -c:v libvpx-vp9 -b:v 2M -deadline realtime -cpu-used 8 -c:a libopus media/closing-clip.webm
# TurboMusic: four short tones so tracks count as having audio (audio/t1.mp3 .. t4.mp3, i = 1..4)
ffmpeg -f lavfi -i "sine=frequency=$((110*i+90)):duration=40" -f lavfi -i "sine=frequency=$(( (110*i+90)*3/2 )):duration=40" -filter_complex "amix=inputs=2,volume=0.3,afade=t=in:d=1,afade=t=out:st=38:d=2" -ac 2 -b:a 96k audio/t$i.mp3
```

## Gotchas found while capturing
- TurboKeep never reaches "network idle" (it holds a live connection), so wait for `load`, not `networkidle`.
- TurboKeep waits to see whether a click becomes a double click: pause about a second after clicking a note before the capture.
- TurboBudget stores money with signs: withdrawals and the outgoing leg of a transfer are negative. Seed them positive and every expense shows as income.
- TurboCut's timeline zoom is pixels per frame (`store.zoom`, default 3): about 1.5 fits a 14 second edit on a 1440 px screen. In a dev checkout the app also shows an "update available" notice; wait it out.
- TurboDocs' slide editor commits text with Escape; clicking elsewhere does not.
- A palette id the app's pinned theme bundle does not know is silently ignored: `turbomusic-light` rendered dark. Look at every capture before using it (this one was caught by looking).
