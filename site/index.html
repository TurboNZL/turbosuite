TurboMusic

Rank your music by asking one question: which is better?

A music library manager for someone who owns their files and cares what ranks first. Head-to-head votes become a 0 to 10 rating for every track, and everything keeps working offline.

Votes
An append-only log. Ratings are replayed from it, so voting on several devices merges cleanly.
Playing
A real queue, rules like “always play B right after A”, crossfade, a ten-band equaliser and synced lyrics.
Library
Eras, albums, releases and notes, with search chips like artist: and rating:.
Sync
Each client holds the whole library and syncs with a small server, for example on a Raspberry Pi.

Runs on: Web (installable) · Windows · Linux · Android and Android Auto · self-hosted server

TurboPantry

A recipe box, a pantry and a shopping list that stays in sync.

Import recipes from websites, keep them in one place, and add only the ingredients you are missing to a list shared by everyone in the home.

Recipes
A recipe shows what you already have and adds just the rest to the list. Scale servings, switch unit modes, mark “I cooked this”.
Shopping
The list updates live on every phone; ticking things off puts them in the pantry.
On a phone
Built phone first: bottom navigation, big touch targets, steppers instead of typing.
Hosting
A few accounts on one self-hosted server, and no paid service anywhere.

Runs on: Web (phone first) · self-hosted server · Android (early)

TurboKeep

To-dos and notes in one small app.

There is one kind of thing: you type something and it is on your list. Tick it to finish it, or send it to tags to keep it.

Tags
With emoji and colour that tint the items, nested, and an optional wall of cards.
Careful
Warns instead of overwriting when the same item changed on another device.
Leaving
Imports and exports Standard Notes, Vikunja and its own backup, so you can go at any time.
Android
An app with a home-screen widget, quick add and a share target.

Runs on: Web · Android · self-hosted server

TurboCut

A lightweight video editor for short vertical clips.

A multi-track editor for short vertical videos, and longer 16:9 edits too, with automatic captions built in.

One codebase

TurboDocs

Documents, spreadsheets and presentations as small apps in one shell.

Docs, Sheets and Slides install into one themed desktop shell and open and save real Word, Excel and PowerPoint files.

Docs
Edits .docx, Markdown and plain text, pageless.
Sheets
Opens .xlsx and .csv. Formulas are kept, but not calculated yet.
Slides
Edits .pptx with a full-screen show and speaker notes.
The shell
Add or remove each app in Settings; the desktop shell updates itself.

TurboBudget

A budget that runs entirely in your browser.

Accounts, subscriptions, debts, interest, taxes, a history timeline and a lot of graphs. There is no server and no account: your data never leaves your device.

Money in, out
Transactions, transfers between accounts and categories, with undo on delete.
Recurring
Subscriptions from daily to every two years, yours, someone else’s, or a loan with a person.
Debts
Repayment history, plus an NZ student loan preset.
Your data
Lives in your browser and in .db files you export yourself.

Runs on: Browser only · no account · NZD, USD, EUR

TurboBox

Keeps your web pages running in the background.

An Android app for pinning a video, a stream or a web app, opening it with one tap, running two at once, and keeping them alive with the screen off. It can record what you missed, and a workflow can click through a page for you.

Pinned pages
Up to four running at once, as tabs or in a split view, with a small floating window to keep one up while you use another app.
Sound
Choose the microphone, mute a page for good, and set page and microphone volume separately.
Missed it?
A recording buffer: step away and the page keeps recording; come back and play what you missed faster than real time.
Privacy
No server, no account, no analytics. Pages, sign-ins and recordings stay on the phone.

Runs on: Android 8 or newer

TurboMC Server

Run, update and manage your Minecraft servers from one familiar window.

A desktop app that keeps every Minecraft server in one list, the way Prism Launcher keeps game installs: pick a version, install mods or plugins from Modrinth, change versions with one click, and start the server with a live console. No Docker, no panel, no web server to babysit.

Install
Vanilla, Paper, Purpur or Fabric, with the download checked against the provider’s checksum when one is published.
Console
Start, stop with a save, or kill. Type commands, search the log, warnings and errors in colour.
Changes
Switch software or version from one page. Nothing updates on its own, and a world backup is taken before a version change.
A fork
It is a fork of Prism Launcher and is not affiliated with that project, Mojang or Microsoft.

Runs on: Linux (.deb, rolling nightly) · Windows and macOS planned

TurboUI

One way to describe a screen, drawn natively on each platform.

Not an app: a toolkit. A screen is written once, in Rust, from plain building blocks (boxes, text) and named theme tokens. TurboUI works out where everything goes, and a thin backend per platform draws the result. TurboMC Server is its first user.

Themes
Palettes are generated from the engine’s real colour themes, with a flat style and a Liquid Glass one, so the colours match the web apps exactly.
Backends
Desktop through GPUI, and a software renderer that is also the reference. Android, iOS and the web are not started.
Checked by
Layout tests and golden-image tests that need no GPU, plus a test that the real GPUI output matches the reference.
Missing
Text input, scrolling, hover, images and animation. It is version zero.

Runs on: Rust 1.88 or newer · cargo test

Looks

One app, as many looks as you like

Every app uses the same theme engine, so a look is a setting, not a rebuild. Below is TurboMusic’s album page in four of them. This page uses the same engine: press Look in the corner to change it, and the screenshots follow (every capture exists in a dark and a light version).

The apps carry up to 33 UI styles and 75 colour palettes. This site loads the neutral set (9 styles, 29 palettes), the one the engine keeps free of other companies’ names and trade dress. The screenshots come in two versions, dark and light, and follow whichever palette is active; they do not follow each palette’s exact colours.

Underneath

One engine underneath

The apps do not share a library. They share a reference: turboengine holds working modules that each app copies, pins to a commit and upgrades on purpose. That is why they feel alike without being tied together.

01

Themes, layouts, motion

One theme package, one set of hook classes, one motion language: new things arrive, a replaced list swaps, a panel slides in, a window pops.

02

Releases that update themselves

Every merge to main becomes a release, numbered by year, month and a counter (like v2026.10.3), and the installed apps update themselves from it.

03

A logo you can tell apart

The engine mark is the same everywhere; each app adds its own emblem in its own colour.
