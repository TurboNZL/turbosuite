# TurboSuite

The public website for the TurboNZL apps: TurboMusic, TurboPantry, TurboKeep, TurboCut, TurboDocs and TurboBudget. A static site with real screenshots of the running apps (no generated images), built on [TurboNZL/turboengine](https://github.com/TurboNZL/turboengine).

(This is the first commit on `main`; the site follows on a work branch.)
